# CLAUDE.md — Dashboard IA Leads/ROI

## Stack fixo
- React
- Tailwind CSS
- shadcn/ui
- Recharts
- Supabase MCP
- n8n MCP

## Objetivo
Construir um dashboard executivo e operacional para leads, IA, custos, ROI, logs e conversões.

## Regras principais
- Manter o escopo por tela.
- Planejar antes de codar.
- Usar mock data antes de conectar banco ou n8n.
- Reutilizar componentes existentes antes de criar novos.
- Não introduzir novas bibliotecas sem aprovação.
- Não usar MCP para exploração ampla.
- Usar MCP apenas de forma pontual e com objetivo claro.
- Manter o visual enterprise, compacto e legível.
- Preferir solução simples e direta.

## Ordem de trabalho
1. Planejar a tela.
2. Construir com mock data.
3. Refinar visual.
4. Validar schema real.
5. Validar workflows n8n.
6. Conectar dados reais.
7. Testar e corrigir.

## Uso de MCP
- shadcn MCP: apenas quando precisar confirmar componente/padrão oficial.
- Supabase MCP: apenas quando tabela/campo já estiverem definidos.
- n8n MCP: apenas quando workflow alvo já estiver definido.

## Proibido
- Fazer sessão gigante com vários objetivos.
- Explorar banco inteiro.
- Explorar todos os workflows.
- Criar design genérico de landing page.
- Reescrever o app inteiro quando uma mudança pequena resolve.
